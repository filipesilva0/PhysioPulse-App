# PhysioPulse 0.15.0

A aplicação passa a atualizar-se sozinha: em Definições › Visão geral, "Procurar atualizações" descarrega e instala as novas versões, que só são aceites se vierem assinadas pela clínica.

## Changes
- In-app updates from GitHub Releases, verified with the owner's updater key and a signed version number (claude/RELEASING.md). Settings › Overview › App row; Check for Updates… in the app menu (Help on Windows); a quiet check after sign-in and twice a day.
- First release built by GitHub Actions: Mac (Apple silicon, with the on-device AI module) and Windows.
- This version must be installed by hand once on each computer; later versions come through the button.

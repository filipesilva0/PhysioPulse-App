# PhysioPulse 0.15.1

A aplicação passa a atualizar-se sozinha: em Definições › Visão geral, "Procurar atualizações" descarrega e instala as novas versões, que só são aceites se vierem assinadas pela clínica. No Mac, o assistente ganha o ditado por voz (Ditar), feito no próprio computador.

## Changes
- First version with a Mac build: 0.15.0's Mac build couldn't start (GitHub retired the macOS 14 machines), so the release workflow now uses the newest macOS on Apple silicon.
- Same app as 0.15.0 otherwise: in-app updates from GitHub Releases, verified with the owner's updater key and a signed version number (claude/RELEASING.md); on-device dictation with whisper.cpp (Whisper large-v3) in the Assistant, read-aloud removed (claude/LOCAL_AI.md).
- Install this version by hand once on each computer; later versions come through the button.
